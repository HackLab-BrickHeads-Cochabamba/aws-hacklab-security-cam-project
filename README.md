# Video Rekognition Project

Project dedicated to detection and tracking of persons on a covered area with cameras using AWS Services and hardware hacking

## Technologies to be used - Software

- AWS Rekognition Service
  - High accurate objects detection, scenes, faces & text
  - Use of the Main API to get an easiest integration
    - StartPersonTracking
      - YOLO
    - StartContentModeration
    - StartFaceDetection(optional)
- Python 3.12
- AWS Lambda
- Amazon S3
- AWS KVS
